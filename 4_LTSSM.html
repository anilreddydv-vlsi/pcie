Based on the PCIe Base Specification LTSSM rules (§4.2.5–4.2.6, Gen3–5, non-Flit mode). The link is shown as x2 (2 lanes, each a TX + RX differential pair) between a Downstream Port (Root Port, the side that leads training) and an Upstream Port (Endpoint). Timeouts are spec values; ordered-set counts are minimums. Link Number 0 is an example value.
